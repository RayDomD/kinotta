Eight tickets to make talking-video reels work

Kinotta can already show a talking video with animations over it, but nothing makes those reels for real yet. Four tickets teach motion-broll to build animations Kinotta can open. Four more teach Claude's skill to build a whole talking-video reel and revise it from your comments.

You can start two of them today. You need to make three decisions first, and each comes with my recommendation.

The gap in one picture

motion-broll makes one web page per animation. A Kinotta version is one page for the whole video, with each animation as a timed scene. motion-broll's engine assumes one animation per page: it uses fixed element names and a single page-wide seek. So a reel page can't just be the clips pasted together.

The tickets

motion-broll learns the Kinotta format (T11)

  1. 01

    Save motion-broll's code history

    motion-broll lives in ~/.agents/skills/motion-broll, which has no git history, so changes to it can't be saved or reviewed. This sets that up. It's the reason T11 was parked.

    Can start now · Model small · Needs decision A

  2. 02

    One motion-broll animation opens in Kinotta

    The build step wraps a clip as a timed scene and names the parts a reviewer could point at (data-el). One example clip then opens in Kinotta, pins land on its named parts, and kinotta check passes. motion-broll's own video export keeps working.

    Waits on 01 · Model mid

  3. 03

    Many animations on one reel page

    The engine learns to run several clips on one page, and the build step combines a whole plan into one reel page, each clip at its moment. A full example, the six-clip demo motion-broll ships with, opens in Kinotta with see-through panels over the video. This is the hardest ticket, because it changes the engine's core.

    Waits on 02 · Model top

  4. 04

    A real motion-broll clip in Kinotta's tests

    The test project's hand-made panel gets replaced by a real motion-broll clip, and the existing footage tests must still pass.

    Waits on 03 · Model mid

Claude's skill learns talking-video reels (T16)

  1. 05

    The checker covers talking-video reels

    kinotta check also catches a missing video file, a broken transcript, or a shot with no type or spoken line, so Claude finds those mistakes before you do.

    Can start now · Model mid

  2. 06

    Build version 1 from a video

    Claude transcribes the video (or uses your subtitle file), splits it into sections by topic, plans the animations with motion-broll's rules, builds them, and puts them together as v1.

    Waits on 03 and 05 · Model top · Needs decisions B and C

  3. 07

    Next version from your comments

    When you hand over one section's comments, Claude rebuilds only that section, leaves the rest untouched, and answers each comment in answers.md.

    Waits on 06 · Model mid

  4. 08

    A real run with you

    On one of your talking videos: review a section, hand it off, and check that v2 changed only that section and kept your unsent comments.

    Waits on 04 and 07 · Yours to do
