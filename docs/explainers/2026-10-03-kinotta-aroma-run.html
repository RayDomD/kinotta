Kinotta · T9 (#11) · K10 · 2026-10-03

Your first real reel in Aroma

Ask Claude for a 15-second brand intro in Aroma. Check the brand file once, review v1 in Kinotta, and paste one batch back. The run passes when v2 arrives with an answers.md and v1's own files are byte-for-byte unchanged.

The skill, the kinotta command and your taste list are already installed. You do everything on this page. Claude never starts the editor (K12). Tick each step as you go; the ticks stay in this browser only.

The run

  1. 01

    Open two terminals in Aroma

    Open them fresh, so they pick up the kinotta command that npm link added. One runs Claude and the other runs the editor.

    cd C:\FIles\Projects\Brands\Aroma
kinotta check
    Expect Usage: kinotta check <reel> [version]. "Command not found" means the terminal predates npm link; open a new one.
  2. 02

    Ask for the reel

    Start Claude in the first terminal and ask in plain words. The skill triggers on "reel", "brand intro" or "Kinotta".

    Make a Kinotta reel: a code-only brand intro for Aroma,
about 15 seconds, 5 to 7 shots.
    Expect Claude writes reels/brand.md with checked: no, summarises it and stops without building (K3). Aroma's DESIGN.md is not empty, so the "no design system" stop (K5) should not fire.
  3. 03

    Check the brand file once

    Open reels/brand.md. It should point at files rather than copy values (K4): DESIGN.md for colour and type, a logo in Assets/, BRAND-GUIDELINES.md and brand-guidelines/, and anything voice-like in context/. Hex codes or font sizes pasted into it are a skill bug, so note them.

    Fix anything wrong, then tell Claude it's right. Claude sets checked: to today's date and builds.

  4. 04

    Let Claude build v1

    Claude reads ~/.kinotta/taste.md, writes reels/<slug>/v1/ (page, assets/, then shots.json last), and runs kinotta check until it's clean.

    Expect a hand-over naming the reel, one line per shot, and an instruction to run kinotta. A still image only: nothing moves until the Review phase (K9).
  5. 05

    Open it in Kinotta

    In the second terminal, run kinotta. It opens the browser on Aroma's reels. Leave it running for the rest of the run.

    Expect the reel listed with v1. Every shot shows a live still and no issue list. A labelled placeholder instead of a frame means the page's seek is broken, a runtime problem kinotta check can't see.
  6. 06

    Pin a few comments and copy the batch

    Enlarge a shot, hover until the element you mean is outlined and named, and click to pin. Do three or four, on different shots, and add one reel note. Then press Copy all comments.

    Expect the clipboard to start with Kinotta comments: <title>, v1 and a Saved as reels/<slug>/v1/comments.json line.
  7. 07

    Snapshot v1, then paste

    Take the snapshot after copying, because Copy itself adds comments.json to v1. Aroma has no git, so hash the files instead. Run this in the editor terminal after stopping kinotta with Ctrl+C, or in a third terminal. Replace brand-intro with the slug Claude chose.

    Get-ChildItem reels\brand-intro\v1 -Recurse -File |
  Get-FileHash | Select-Object Hash, Path |
  Export-Csv $env:TEMP\v1-before.csv -NoTypeInformation

    Paste the batch into Claude.

  8. 08

    Let Claude build v2

    Expect v2/ copied from v1, edited, answers.md with every comment marked Done, Partly done or Not done (with a reason), shots.json last with changedSections, and a clean kinotta check. Claude repeats the answers in chat (K6).

    If kinotta was still running, it shows v2 as ready. Otherwise start it again.

  9. 09

    Prove v1 didn't change

    $before = Import-Csv $env:TEMP\v1-before.csv
$after  = Get-ChildItem reels\brand-intro\v1 -Recurse -File |
  Get-FileHash | Select-Object Hash, Path
Compare-Object $before $after -Property Hash, Path
    Expect no output. Any line means v1 was touched, which breaks K12. Keep that output for the bug report.
  10. 10

    Close T9

    In the Kinotta repo, tick the last box under T9 in docs/tickets.md: "A real run in Aroma: v1 opens in Kinotta, a batch produces v2 with answers.md, v1 stays unchanged (K10)". Then mark T9 done and note anything the run taught you about the skill.
