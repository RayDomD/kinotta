How it works, and what's gone

Doing things

  • Click a row to hear or see it. It plays in the main frame and speakers, not in a mini player in the list.
  • + adds it at the playhead on the right track: sound to the first audio track with room (a new one if none), video and stills to Inserts.
  • Drag a row onto any track or lane for exact placement. Dropping on Footage puts it in the main cut.
  • Problems only get a label: Missing → Relink opens a file picker, Import failed → Retry.

Removed from today's library

  • The separate "In this project" list and "Add to library": project files are just in the list.
  • Append / Insert picture / Add sound buttons: one + and drag.
  • Preview / Close preview buttons and the inline player.
  • "ready" on every row, the Relink dropdown, help paragraphs.
  • The Type dropdown becomes four tabs.

Still covered

Import by drop or button and Retry (AM15), search, type filter, preview, reuse across reels (AM10), exact-content relink (AM25).
